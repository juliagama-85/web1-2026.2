Cascading Style Sheets - CSS

Sobre CSS:

O CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é a linguagem de estilização usada para definir a aparência visual de páginas web criadas em HTML.

o que o CSS faz?

Aparência: Controla cores, fontes, tamanhos de texto e planos de fundo. Layout: Organiza a posição dos elementos na tela usando o modelo de caixas (box model).] Responsividade: Adapta o site para diferentes tamanhos de tela, como celulares e computadores.
